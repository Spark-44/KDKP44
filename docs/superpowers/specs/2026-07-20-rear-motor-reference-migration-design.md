# 后轮驱动参考版本迁移设计

## 目标

将 `D:\tools\Infineon\ADS_Workspace\kart_508-kmy\kart_508` 中的后轮驱动实现迁移到当前工程，同时保留当前工程已有的科目二、遥控、串口诊断和其他未提交修改。

迁移后的核心行为以参考工程为准，包括：

- HIP 四路 PWM 后轮输出；
- 固定 10 ms 编码器采样；
- 编码器脉冲与同时刻航向成对缓存；
- 100 ms 速度窗口、速度滤波和参考版 PID/前馈参数；
- 左右后轮差动前馈；
- 非阻塞主动制动；
- 参考版编码器标定和里程计缓冲。

## 迁移边界

完整迁入参考工程的以下后轮模块：

- `code/rear_motor/rear_motor.c`
- `code/rear_motor/rear_motor.h`
- `code/rear_motor/rear_encoder_calibration.h`
- `code/rear_motor/rear_odometry_buffer.h`
- `code/rear_motor/rear_odometry_pose_buffer.h`

对当前工程的调用链做局部适配：

- `code/peripheral.h`：只加入参考驱动要求的后轮 PWM 和编码器别名，不覆盖当前舵机、按键及其他硬件配置；
- `code/peripheral.c`：确保旧 `Motor_init()` 和 `Moter_Set()` 使用同一套四路 PWM 定义，避免旧入口与新驱动争用不同硬件语义；
- `user/isr.c`：10 ms 采样调用传入当前 `Yaw_1`；
- `code/guandao.c`：科目一里程积分消费“编码器脉冲 + 采样航向”队列；
- `user/cpu0_main.c`：更新采样调用和后轮诊断接口，同时保留科目二主循环；
- `code/remote_control.c`：更新采样调用，并保留当前遥控速度限制行为。

不整文件覆盖 `peripheral.*`、`guandao.c`、`cpu0_main.c`、`isr.c` 或 `remote_control.c`，以免删除当前工程独有功能。

## 兼容策略

参考驱动作为唯一后轮硬件控制核心。当前工程独有接口按以下方式兼容：

- `rear_motor_set_full_power()`：保留公开接口，但通过参考版四路 PWM 输出路径执行，并服从参考驱动的硬限幅；
- `rear_motor_set_speed_limit_mps()` 与 `rear_motor_clear_speed_limit()`：保留遥控限速语义，并在参考版 PID 输出计算中实施同方向超速抑制；
- 旧总脉冲和总距离诊断：调用点迁移到参考版里程累计接口；距离继续使用当前科目一路程标定，避免同时存在两套累计状态；
- `rear_motor_clear_odometer()`：若无运行时调用则删除旧声明；若测试或调用链仍依赖，则实现为同时清空参考版累计值和样本缓冲。

所有直接调用 `rear_motor_encoder_update_10ms()` 的位置都必须传入同一时刻的 `Yaw_1`。各运行模式继续沿用当前的互斥调度，不新增第二个硬件采样器。

## 数据流

1. 10 ms 周期入口读取 TIM2 后轮编码器，并将脉冲增量与 `Yaw_1` 写入固定容量队列。
2. 同一采样同时进入 100 ms 速度窗口，用于参考版速度滤波和 PID。
3. 科目一主循环逐个取出里程样本，按每个样本自己的航向投影到 `x/y`，避免主循环阻塞时把整段距离投影到最后一个航向。
4. 科目二和遥控继续设置目标速度或开环输出，但实际后轮输出统一经过参考版四路 PWM 路径。
5. 停车和主动制动均清理必要控制状态，并确保四个 PWM 通道归零。

## 安全与错误处理

- 保留参考版编码器异常增量限幅，异常样本不进入速度和里程计算；
- 样本队列满时使用参考版合并策略，累计脉冲不丢失，并记录合并计数；
- 主动制动使用参考版低速、反转和超时退出条件；
- `rear_motor_stop()` 必须停止四个 PWM 通道并取消主动制动；
- 硬件宏只做后轮相关最小修改，避免改变当前工程的转向和通信引脚。

## 测试与验收

实施采用测试优先：先把参考工程的后轮接口、全局制动和 HIP 通道映射测试移入当前工程，并补充当前独有接口兼容测试；确认这些测试在旧实现上按预期失败后再改生产代码。

验收条件：

- 参考版后轮测试全部通过；
- 当前工程现有 PowerShell 和 Python 测试全部通过，或明确记录与本迁移无关的既有失败；
- 所有后轮采样调用均传入 `Yaw_1`；
- 科目一不再通过旧 `Encoder_Get()` 路径读取 TIM2 作为里程来源；
- 四路 PWM 映射与参考工程一致，停车时四通道全部为零；
- 当前科目二、遥控限速、全功率和串口诊断调用仍可链接；
- ADS Debug 构建成功；
- `git diff --check` 无新增格式错误。

本次不修改参考工程，不覆盖当前工程中与后轮迁移无关的现有改动，也不做额外重构或参数调优。
